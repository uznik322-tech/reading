# Правила работы над проектом

## Описание проекта
«Между строк» — личная читалка FB2 в формате PWA.
Основной сценарий: загрузить книгу, читать на Android или компьютере,
продолжить с сохранённого места на другом устройстве.

## Область работы
- Работай только в папке reading. Не создавай и не изменяй файлы за её пределами.
- Не изменяй и не удаляй файл agents.md без явного подтверждения пользователя.
- Перед изменениями изучи readme.md и соответствующие файлы проекта.
- Не удаляй существующие файлы без явного подтверждения.
- Не изменяй системные настройки компьютера.

## Язык и именование
- Отвечай пользователю по-русски.
- Тексты интерфейса, документацию и комментарии пиши по-русски.
- Имена файлов и переменных — на английском, маленькими буквами.
- Для составных имён переменных используй snake_case.

## Технический подход
- Интерфейс: HTML, CSS и JavaScript без сборки.
- Сервер: Node.js 20+ со встроенными модулями.
- Не добавляй зависимости без объяснения, зачем они нужны.
- Предпочитай небольшие изменения и простые решения.
- Не добавляй возможности вне текущей задачи.

## Интерфейс
- Сохраняй минималистичный стиль и удобство длительного чтения.
- Сначала учитывай использование на телефоне.
- Проверяй светлую, бумажную и тёмную темы.
- Не допускай горизонтальной прокрутки интерфейса.
- Используй понятные подписи, доступные кнопки и видимый фокус.
- Не загружай шрифты и другие ресурсы с внешних сайтов.

## Книги и прогресс
- Считай содержимое FB2 недоверенными данными.
- Не вставляй текст книги через innerHTML.
- Сохраняй место по позиции в тексте, а не по номеру страницы.
- Сохраняй позицию при изменении размера шрифта и ширины экрана.
- Чтение и локальное сохранение должны работать без интернета.
- Не перезаписывай конфликтующий прогресс без выбора пользователя.
- Ошибки синхронизации не должны мешать чтению.

## Данные и безопасность
- Не изменяй пользовательские книги и reading/data вручную.
- Не используй настоящую библиотеку в автоматических тестах.
- Не сохраняй пароли, сессии и содержимое книг в логах.
- Не добавляй секреты и папку data в Git.
- Не публикуй приложение и книги без прямого запроса пользователя.

## PWA
- После изменения файлов офлайн-оболочки обновляй cache_name в sw.js.
- Офлайн-ресурсы читай из кэша текущей версии.
- Не кэшируй ответы API с личными данными.
- Не перезагружай приложение принудительно во время чтения.

## Проверка изменений
- Проверяй синтаксис изменённых JavaScript-файлов.
- При изменениях сервера запускай node --test.
- Для исправлений ошибок добавляй тест, если он помогает предотвратить повторение.
- Изменения интерфейса проверяй в браузере, включая мобильную ширину.
- Для изменений сохранения проверяй восстановление позиции после перезагрузки.
- Для изменений PWA проверяй работу при недоступном сервере.
- Обновляй readme.md, если меняются запуск, настройка или ограничения.

## Завершение задачи
- Кратко сообщи, что сделано и какие файлы изменены.
- Укажи выполненные проверки.
- Отдельно назови то, что не проверено или осталось незавершённым.
