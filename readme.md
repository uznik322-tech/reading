# Между строк

Личная читалка FB2 для компьютера и Android. Библиотека и место чтения хранятся на устройстве. Облачной синхронизации и входа больше нет. Кнопка Telegram отправляет название, автора, процент, главу и фрагмент текста в твой личный чат с ботом.

Есть две версии с общим интерфейсом: PWA для браузера и APK для Android. Установка APK, настройка бота на телефоне и сборка описаны в [android.md](android.md). В APK книги и интерфейс доступны без сервера; Telegram работает напрямую через Android.

## Запуск

Для разработки и Android-сборки нужен Node.js 22 или новее. Сервер использует только встроенные модули Node.js; Capacitor нужен для упаковки APK. Из папки reading:

```powershell
node server.js
```

Открыть http://127.0.0.1:3188. Без настройки бота можно читать, импортировать книги и сохранять место. Тестовую книгу можно добавить кнопкой в пустой библиотеке.

## Создание бота с нуля

1. Открыть официальный https://t.me/BotFather в Telegram.
2. Отправить `/newbot`.
3. Указать имя, например «Между строк».
4. Указать свободное имя пользователя, заканчивающееся на `bot`, например `my_reading_notes_bot`. Если занято — выбрать другое.
5. Скопировать выданный токен в локальный файл `reading/.env`, в строку `TELEGRAM_BOT_TOKEN=`. Токен не отправлять в чат, не вставлять в адресную строку браузера и не коммитить.
6. Запустить из reading:

```powershell
node setup-bot.js
```

Скрипт проверит токен, покажет ссылку на твоего бота и случайный одноразовый код. Открыть ссылку, нажать «Начать» и отправить код в личный чат с ботом в течение двух минут. Скрипт сохранит TELEGRAM_CHAT_ID в .env. Это не отправляет тестовое сообщение: первое сообщение с прогрессом отправляется вручную кнопкой в читалке.

После настройки перезапустить сервер. Скрипт не нужен при обычном запуске. Если используется другой компьютер или хостинг, перенести настройки через переменные окружения или отдельный .env, не через Git. Для нового места запуска есть .env.example.

Бот работает через HTTP Bot API. В обычном режиме polling и webhook не нужны: сервер вызывает sendMessage при нажатии кнопки. getUpdates используется только один раз при привязке чата. Не использовать одного бота одновременно с другим сервисом, который получает его обновления.

Официальная инструкция: https://core.telegram.org/bots/tutorial

## Как переносить место чтения

- Открыть книгу, нажать «Telegram ↗» и проверить предпросмотр.
- Нажать «Отправить в Telegram». Нужно соединение с сервером и интернет на сервере.
- На другом устройстве отдельно загрузить тот же FB2.
- Нажать процент внизу читалки, ввести значение из сообщения.
- Уточнить место по главе и фрагменту. Процент зависит от оформления и приблизителен.

Ничего не отправляется автоматически. Полный файл книги на сервер не загружается. При сетевой ошибке прогресс остаётся локально. Автоматической очереди повторной отправки нет; после тайм-аута проверить чат, чтобы не отправить дубликат.

## Телефон и PWA

Для установки на Android и офлайн-режима нужен постоянный HTTPS-адрес сервера. На компьютере localhost работает для разработки; localhost телефона не указывает на компьютер.

На хостинге задать HOST=0.0.0.0, нужный PORT, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID и READING_ORIGIN=https://твой-домен (без слеша в конце). Запустить node server.js за HTTPS-прокси. Открыть этот адрес в Chrome на Android и выбрать «Установить приложение» или «Добавить на главный экран».

После первой загрузки оболочки и импорта книги читать можно без интернета. Telegram без интернета не работает. Не очищать данные сайта: это удалит локальную библиотеку. Резервной копии и восстановления из Telegram нет.

## Хранение и доступ

Токен и chat_id хранятся на сервере. Браузер получает только признак готовности бота. Получателя нельзя изменить запросом из браузера. Сервер не обслуживает .env, внутренние модули и папку data. Между отправками есть общая пауза 10 секунд.

Входа на сайт нет. Любой, кто получил доступ к опубликованному сайту, сможет нажать отправку в настроенный личный чат; изменить получателя или прочитать библиотеку другого устройства он не сможет. Это вариант для личного использования.

Сервер не хранит библиотеку на диске. Книги находятся в IndexedDB браузера или Android WebView; эти библиотеки раздельные.

## Возможности и ограничения

Есть импорт .fb2 до 16 МБ, обложки, каталог, поиск по автору/названию, оглавление, внутренние ссылки, прокрутка, сохранение позиции по блоку текста, размер шрифта, межстрочный интервал, три темы, офлайн-оболочка PWA.

Нет ZIP, EPUB, PDF, удаления книг, цитат, ручных закладок, поиска по тексту, автоматической передачи файлов и прогресса между устройствами. Необычные FB2 могут потребовать доработок.

## Проверка

```powershell
node --check app.js
node --check server.js
node --check setup-bot.js
node --test
```

Тесты Telegram используют подмену сетевого запроса, без настоящего токена и отправки сообщений. Серверный тест работает в собственной временной папке внутри reading и убирает только свои файлы.

Ручная проверка: открыть sample.fb2, перейти к 37.2%, проверить предпросмотр Telegram, смену темы, сохранение после перезагрузки и работу без сервера. После настройки настоящего бота отдельно проверить доставку сообщения. Установка на физическом Android и публичное размещение пока не проверены.

В Chrome проверены мобильный диалог, три темы, предпросмотр, переход по проценту и восстановление локального чтения после перезагрузки при остановленном сервере. В PWA при недоступности сервера отправка блокируется с понятным сообщением. В APK отправка идёт через нативный модуль, настроенный на телефоне. Доставку с реального Android нужно проверить отдельно.

При изменении оболочки повышать cache_name в sw.js. При крупных обновлениях также менять version в URL регистрации service worker в app.js. Не менять agents.md без явного подтверждения пользователя.
