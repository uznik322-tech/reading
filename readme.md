# Между строк

Личная читалка FB2 для компьютера и Android. Минималистичная библиотека, оглавление, автоматическое сохранение места, настройки текста и чтение без интернета. Сервер синхронизирует книги и прогресс между устройствами, подключёнными к одному адресу.

## Быстрый запуск

Нужен Node.js 20 или новее. Внешних библиотек нет, `npm install` не требуется.

В PowerShell из папки `reading`:

```powershell
node server.js
```

Открыть http://127.0.0.1:3188. Книги и место чтения сохраняются в браузере даже без входа. Пример для проверки импорта — `sample.fb2`; он не добавляется автоматически.

## Синхронизация

Остановить сервер сочетанием Ctrl+C и запустить с личным паролем:

```powershell
$env:READING_PASSWORD = 'замени-на-свой-длинный-пароль'
node server.js
```

Нажать «Синхронизация» и ввести этот пароль на обоих устройствах. Это одна личная библиотека, без регистрации и отдельных пользователей. Не использовать пример пароля буквально. Сессии действуют до семи дней, после перезапуска сервера требуется повторный вход.

Сервер сохраняет библиотеку в `reading/data/library.json`. Для резервной копии сохрани всю папку `data`. Локальные книги остаются в браузере после выхода; на чужих устройствах не входить.

## Телефон и установка

Для полноценной установки на Android и офлайн-режима нужен постоянный HTTPS-адрес сервера. `localhost` на компьютере доступен только этому компьютеру. Публикация и настройка хостинга в эту версию не входят.

На хостинге запустить `node server.js`, задать `HOST=0.0.0.0`, `PORT` по требованиям хостинга, `READING_PASSWORD`, `READING_ORIGIN=https://твой-домен` и `COOKIE_SECURE=1`. Перед Node.js должен быть HTTPS-прокси. Для `reading/data` обязательно постоянное хранилище: временный диск хостинга потеряет библиотеку после пересоздания контейнера. Нужен один процесс сервера; запись рассчитана на личное использование.

Открыть HTTPS-адрес в Chrome на Android, выбрать «Установить приложение» или «Добавить на главный экран». На компьютере открыть тот же адрес. Войти с одинаковым паролем. После первой успешной загрузки приложения и книги они доступны офлайн; для синхронизации снова нужен интернет. Не очищать данные сайта: это удалит локальные книги и ещё не отправленный прогресс.

## Что реализовано

- Импорт одного `.fb2` до 16 МБ, извлечение названия, автора, встроенной обложки и изображений.
- Библиотека с поиском и последней открытой книгой.
- Вертикальная прокрутка, оглавление, внутренние ссылки и примечания в конце книги.
- Размер текста, три межстрочных интервала, три темы.
- Позиция по абзацу и смещению вместо нестабильного номера страницы.
- Локальное хранение в IndexedDB и офлайн-оболочка PWA.
- Синхронизация при входе, возврате в приложение, восстановлении сети и после остановки прокрутки.
- Проверка версии прогресса на сервере: при конфликте пользователь выбирает нужное место.
- Пароль, HttpOnly-сессия, ограничение попыток входа и запрет доступа к файлам библиотеки через HTTP.

## Границы первой версии

Нет ZIP, EPUB, PDF, удаления книг, цитат, ручных закладок и поиска по тексту. Примечания открываются переходом внутри книги, без всплывающих карточек. Большие библиотеки целиком загружаются при синхронизации — это вариант для личного небольшого каталога. Файл не конвертируется на сервере; нестандартные FB2 могут потребовать доработок. Поддержка UTF-8, UTF-16 и Windows-1251 зависит от стандартного TextDecoder браузера.

Приложение не опубликовано. Работа и установка на физическом Android пока не проверены. При офлайн-чтении закрытие приложения в момент сохранения может потерять последние доли секунды прокрутки. Автоматической резервной копии нет.

В Chrome проверены разбор тестовой FB2, каталог, чтение, оглавление, изменение шрифта и темы, сохранение и восстановление позиции после перезагрузки. Мобильная вёрстка проверена при размере 390 × 844. Автоматический выбор локального файла заблокирован настройками расширения Chrome; настройки не менялись. Встроенная кнопка тестовой книги использует тот же обработчик импорта.

Офлайн-оболочка проверена остановкой локального сервера: после перезагрузки доступны библиотека, текст и сохранённая позиция. При изменении файлов оболочки повышать версию `cache_name` в `sw.js`, чтобы офлайн-копия обновилась.

## Проверка

```powershell
node --check app.js
node --check server.js
node --test
```

Серверный тест создаёт собственную временную папку внутри `reading`, проверяет вход, сохранение, конфликт версий, выход и закрытость файлов данных, затем убирает только свои временные файлы.

Для ручной проверки: импортировать `sample.fb2`, открыть главу, прокрутить, вернуться в библиотеку и перезагрузить страницу. Проверить восстановление позиции, изменение шрифта и темы. Для двух устройств — открыть опубликованный сервер в двух браузерах, войти, открыть книгу, проверить перенос прогресса и конфликт после офлайн-чтения.
